# OhMyFood

Site web mobile-first pour OhMyFood, plateforme de réservation et composition de menus en ligne pour restaurants gastronomiques, développé pour son lancement à Paris.

Le site présente les menus de 4 restaurants gastronomiques et permet aux utilisateurs de composer leur commande à l'avance.

**Technologies :** HTML5, CSS3/Sass, sans JavaScript, sans framework — approche Mobile First.

**Auteur :** Nicolas Raux — Projet réalisé dans le cadre de la formation Intégrateur  Web, OpenClassrooms.
